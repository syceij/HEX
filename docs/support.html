Common questions

  • I didn’t get my sign-in code email
    Check your spam/junk folder. Codes arrive within a minute. If it still hasn’t come, wait a moment and request a new one.
  • How do I delete my account?
    Open the app → Profile → Settings → Delete Account. This permanently removes all your data.
  • How do I turn notifications on or off?
    Profile → Settings → Notifications. You can toggle each type individually.
  • How do I add a friend?
    Go to the Bros tab → tap the + → share your invite link or search by username.
  • My data looks wrong / didn’t save
    Make sure you have a stable internet connection and the latest version of the app, then reopen it. If it persists, email us with details.
